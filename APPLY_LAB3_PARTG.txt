APPLY THE LAB 3 PART G UPDATE

IMPORTANT: Make a backup of your current skill-nexa folder first.

1. Extract this ZIP.
2. Open the extracted skill-nexa folder.
3. Copy its files into your existing skill-nexa project folder.
4. Choose Replace when Windows asks about files with the same names.
5. KEEP your existing .env file. It contains your local PostgreSQL settings and password. The ZIP intentionally does not include .env.
6. KEEP your existing .git folder. This preserves your GitHub repository connection.
7. KEEP your existing node_modules folder. You can also run npm install if Node reports a missing package.
8. Confirm .env has DB_PORT=1793, because your pgAdmin server connection uses port 1793.
9. Confirm pgAdmin is connected to the skill_nexa_db database, and that db/labs/lab3.sql has already been executed there.
10. Run npm run seed if you have not already inserted the sample companies and jobs.
11. Run npm run dev.
